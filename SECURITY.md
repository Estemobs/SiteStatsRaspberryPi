# Sécurité

SiteStatsRaspberryPi stocke les mesures (température, CPU, RAM) dans une base SQLite locale. L'accès aux mesures distantes est protégé par un jeton Bearer ; aucun secret ne doit être commité.

## Signaler une vulnérabilité

- Ne publiez **pas** la vulnérabilité dans une issue publique.
- Utilisez la [signalisation privée de vulnérabilité GitHub](https://github.com/Estemobs/SiteStatsRaspberryPi/security/advisories) (Security tab → Report a vulnerability).

Vous recevrez un accusé de réception sous quelques jours. Merci de ne pas exploiter la faille et de donner un délai raisonnable avant toute divulgation.
